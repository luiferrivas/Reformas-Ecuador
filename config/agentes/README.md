# 🤖 Configuración y Doctrina Operativa de Agentes

Este directorio contiene las especificaciones operativas, plantillas y reglas inviolables de ejecución que rigen la conducta, cálculo y análisis de todos los agentes IA y subagentes que participan en el proyecto **Reformas Ecuador**, adoptando la doctrina técnica del **Consorcio Industrial Olimpo**.

---

## 📂 Contenido del Módulo

| Archivo | Propósito |
| :--- | :--- |
| **[`doctrina.yaml`](./doctrina.yaml)** | Configuración legible por máquinas con las 12 reglas inviolables, umbrales de validación y formatos requeridos. |
| **[`system_prompt_base.md`](./system_prompt_base.md)** | Prompt de sistema maestro listo para inyectarse en subagentes, modelos o pipelines de análisis. |
| **[`SUMMARY_TEMPLATE.md`](./SUMMARY_TEMPLATE.md)** | Plantilla estándar obligatoria del archivo `SUMMARY.md` (L1 Cache) por cada subproyecto (Mandamiento 9). |
| **[`HISTORICO_HEADER_TEMPLATE.md`](./HISTORICO_HEADER_TEMPLATE.md)** | Plantilla de cabecera forense para archivos descartados movidos a la carpeta `historico/` (Mandamiento 12). |

## 🏛️ Los 12 Mandamientos Inviolables (Resumen de Impacto Técnico)

1. **No Complacencia:** Rigor crítico implacable; señalar deficiencias de inmediato.
2. **Cero Positivismo Naive:** Prohibido maquillar cifras o inventar eficiencias irreales.
3. **Realismo Estricto:** Fiel observancia de la física, termodinámica y economía de mercado.
4. **No Omitir Realidad Empírica:** Confrontar modelos teóricos contra datos de campo y laboratorio.
5. **Compatibilidad Estricta LaTeX / KaTeX:** Separación estricta de tablas Markdown y bloques KaTeX (`$$ ... $$`), sin `$` en celdas de tablas, y sintaxis `\text{...}` para unidades.
6. **Bitácora de Decisiones y Descartes:** Obligatoria en cada informe técnico para preservar la memoria histórica y justificar el descarte de alternativas.
7. **Cero Dependencia de Subsidios:** Autosuficiencia 100% de mercado. Incentivos externos (bonos de carbono, créditos verdes) solo como *upside marginal secundario*, nunca como base de flujo de caja.
8. **Formato Obligatorio de Monedas:** Dólar estadounidense como base principal (`USD`) y moneda local entre paréntesis (`USD (MONEDA)`).
9. **Archivo SUMMARY.md Obligatorio:** L1 Cache contractual, técnico y financiero en la raíz de cada subproyecto, sujeto a la Regla de Cero Deriva.
10. **Cálculo Riguroso de Payback y Doble Métrica:** Prohibido calcular Payback sobre EBITDA bruto; deducir 15% utilidades + 25% IR en Ecuador (36.25% tasa efectiva agregada) y reportar Payback Crudo de Resistencia vs. Payback Acelerado por Negociación Estatal.
11. **Benchmark de Petróleo (WTI Base):** WTI en `USD/bbl` como referencia obligatoria principal; Brent únicamente como spread comparativo secundario.
12. **Protocolo de Carpetas `historico/`:** Archivar versiones obsoletas con cabecera forense y enlaces directos (`file:///...`), manteniendo la raíz limpia con documentos vigentes.
